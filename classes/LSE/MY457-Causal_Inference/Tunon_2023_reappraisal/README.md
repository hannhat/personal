### Summary

This is a reappraisal of When the Church Votes Left: How Progressive Bishops Supported the Workers' Party in Brazil (Tuñón 2023). All file paths given in this document are relative to the directory this .README file is in.

### File Structure

- `MY457_reappraisal.html` is my main document and is generated by `MY457_reappraisal.qmd`.
- The `analysis_code` folder contains all the code I wrote to explore the data and write helper functions for the results in my main document. `analysis_code/main_file_helpers.R` contains all the helper functions I call to generate my main file results. It is sourced at the top of `MY457_reappraisal.qmd`.
- `replication_files` is a copy of the replication files downloaded from Tunon (2026), plus the output LaTeX tables and plots from running the paper's code scripts. The `replication_files/output` folder is created by running these scripts. I have additionally added a LaTeX file titled `replication_files/output/view_tables.tex` to view all the LaTeX tables together.

### Data Instructions

The data used to generate the results in my reappraisal come from this link to the replication data for this paper: <https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/YGBWHC> This link includes instructions for how to replicate the main results of the paper.

To run my results, please download the files from the above link and paste the `.csv` files into the `replication_files/data` folder.
