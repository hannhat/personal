# Dissertation code files 

- `vr_effects_sm_data.R` provides functions for Monte Carlo estimation of interventional effects for one and two mediators. There is functionality for estimation of 
  VanderWeele-Robinson, Lin-VanderWeele, and Vansteelandt-Daniel effects, though only VanderWeele-Robinson effects are included in the dissertation. 
- `sm_data_application.R` provides the code for generating Tables 3-8 of the dissertation.
